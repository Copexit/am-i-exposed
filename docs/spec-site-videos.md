# Site Videos - promo on the home page, /tutorial page

Status: design approved in conversation (2026-10-05), pending spec review.

---

## Why

A tester asked to show the existing videos on the site: the 60 s promo (es/en, 16:9 and 9:16) and the narrated 5-minute tutorial (es/en, 16:9). They help a newcomer understand the tool quickly and learn to use it. They are published on the GitHub-hosted site only: self-hosted copies (Umbrel, StartOS, Docker) never show them nor carry the files.

## Goals

1. The promo plays from the home page "How it works" section, vertical on portrait screens and horizontal otherwise, in the visitor's language.
2. A new `/tutorial` page plays the tutorial with subtitles in all 6 UI languages, a chapter list and "try it yourself" example scans.
3. Nothing is downloaded before the visitor presses play; no third-party player, host or tracker.
4. Self-hosted builds show no video UI and their Docker image contains no media files.

## Non-goals

- Re-recording the tutorial for features added after it was recorded (0.37.3).
- Dubbed audio in de/fr/pt/pl.
- A download button, autoplay, or analytics of any kind.

---

## Decisions (owner, 2026-10-05)

| Topic | Decision |
|---|---|
| Promo placement | Home, top of the "How it works" section, poster card |
| Tutorial placement | New `/tutorial` page |
| Links to /tutorial | Home "How it works", top navigation, footer, About and Welcome pages |
| Hosting | Main repo under `public/media`, excluded from Docker builds |
| Languages | es/en audio; subtitles in en, es, de, fr, pt, pl |
| Orientation | Chosen by screen shape at play time: portrait -> 9:16, otherwise 16:9 (promo only) |
| Playback | Poster with play button, `preload="none"`, click to play, native controls, no autoplay |
| Subtitles | Always on, in the UI language, switchable |
| Tutorial page content | Player, chapter list with jump links, try-it example buttons |
| GitHub-only enforcement | Build flag `NEXT_PUBLIC_VIDEOS=1` set only by the GitHub Pages workflow |
| Encoding | 720p H.264, about 10-15 MB per file |

## 1. Assets

All under `public/media/`, generated by `scripts/encode-media.sh` from the masters in `~/Videos/am-i-exposed/` (the script takes the masters directory as an argument):

| File | Source | Encoding |
|---|---|---|
| `promo-en-16x9.mp4`, `promo-es-16x9.mp4` | `am-i-exposed-{en,es}-16x9.mp4` (1080p60) | 1280x720, 30 fps, H.264 High, CRF tuned (target 6-9 MB), AAC 128k stereo, `+faststart` |
| `promo-en-9x16.mp4`, `promo-es-9x16.mp4` | `am-i-exposed-{en,es}-9x16.mp4` | 720x1280, same settings |
| `tutorial-en-16x9.mp4`, `tutorial-es-16x9.mp4` | `tutorial/tutorial-{en,es}-16x9.mp4` (no burned subtitles) | 1280x720, 30 fps, H.264 High, CRF tuned so UI text stays legible (target 12-18 MB), AAC 96k mono, `+faststart` |
| `promo-*-{16x9,9x16}.webp`, `tutorial-*.webp` | Representative frame of each video | Same dimensions as the video, WebP q80 (about 50 KB) |
| `tutorial-{en,es,de,fr,pt,pl}.vtt` | en/es from `tutorial-{en,es}.srt`; de/fr/pt/pl translated from the English cues, keeping the English timings | WebVTT, UTF-8 |

If 720p tutorial text is not legible at the target size, a 1080p comparison is shown to the owner before committing.

The promo has no narration and its on-screen text is in its own language, so it has no subtitle track.

Chapter times come from `tutorial/source/edl-{en,es}.json` and are stored in code (`src/lib/media/tutorial-chapters.ts`):

| Chapter | en start (s) | es start (s) |
|---|---|---|
| What am-i.exposed is | 3.2 | 3.2 |
| The home page | 32.33 | 32.97 |
| Scanning a transaction | 66.6 | 68.77 |
| A good example: CoinJoin | 161.43 | 169.3 |
| Analyst tools | 198.6 | 203.7 |
| Checking an address | 225.73 | 235.7 |
| More privacy | 251.7 | 261.13 |

Chapter titles are i18n keys (`tutorial.chapter.*`) in 6 locales.

## 2. GitHub-only enforcement

- `src/lib/media/videos-enabled.ts`: `export const VIDEOS_ENABLED = process.env.NEXT_PUBLIC_VIDEOS === "1";` (inlined at build time).
- `.github/workflows/deploy.yml` sets `NEXT_PUBLIC_VIDEOS: "1"` on the build step. CI, local builds and Docker builds leave it unset.
- `.dockerignore` adds `public/media`, so the Umbrel/StartOS images never contain the files even if a build sets the flag.
- `scripts/generate-sitemap.mjs` lists `/tutorial` only when the flag is set.
- With the flag off: no home card, no nav/footer/About/Welcome links, and `/tutorial` (the route always exists in a static export) renders a short note "The video tutorial is available on am-i.exposed" with a link, and `noindex`.

## 3. Components

| Unit | Responsibility |
|---|---|
| `src/lib/media/video-sources.ts` | Pure: `pickVideoLang(uiLang): "es" \| "en"`, `promoSource(lang, portrait)`, `tutorialSource(lang)`, `posterFor(...)`, `subtitleTracks(uiLang)` (6 tracks, default = UI language, falls back to en for unknown languages) |
| `src/components/media/PosterVideo.tsx` | Poster box with exact aspect ratio and a play `<button>`; on click mounts `<video controls playsInline autoPlay preload="none">` with the chosen source and tracks; error state with a link to the file; exposes `seek(seconds)` via ref for chapters |
| `src/components/home/PromoCard.tsx` | Home "How it works" card: decides orientation with `matchMedia("(orientation: portrait)")` at click time, renders PosterVideo, and the "Watch the 5-minute tutorial" link |
| `src/components/pages/TutorialPage.tsx` + `src/app/tutorial/{page,layout}.tsx` | Player, chapter list (buttons with mm:ss, seek and play), try-it examples (reusing the existing EXAMPLES list for the cases shown in the video), flag-off note; metadata, Open Graph image like other pages |
| Nav / footer / About / Welcome | One conditional link each, gated on `VIDEOS_ENABLED` |

Layout rules: the 9:16 promo is centered with height capped at about 80vh; 16:9 players take the content width; the poster box reserves the final aspect ratio (no layout shift); no horizontal scroll at 390 px. Language changes apply to the next play; a playing video continues.

Accessibility: the play buttons have accessible names ("Play the 1-minute overview", "Play the tutorial"); the video has an `aria-label`; chapter buttons read "m:ss title"; subtitles act as captions.

## 4. Copy

New keys in all 6 locales (es Castilian tuteo, no em dashes, no "we/us/our"): nav/footer "Tutorial", home card title and link, tutorial page title, intro, chapter heading and the 7 chapter titles, try-it heading and button labels, play button names, video error text, flag-off note, page metadata.

## 5. Privacy

- Same origin as the site: no CSP change, no third-party request.
- `preload="none"` and a poster image: no video bytes before a click. Posters are small images loaded with the page.
- No analytics, no autoplay.

## Testing

- Unit:
  - `pickVideoLang`, `promoSource` (language x orientation) and `subtitleTracks` (default track per UI language, unknown language falls back to en).
  - `PosterVideo`: no `<video>` before click; after click, the source and default track are set; the error state renders.
  - Chapter click seeks and plays.
  - Flag gating with the flag on and off: home card, nav, footer, About, Welcome, `/tutorial` content.
  - Every `.vtt` file parses as WebVTT; en/es cue counts match their `.srt`; de/fr/pt/pl cue counts and timings match en.
  - Chapter keys present in all 6 locales (existing parity test).
  - `.dockerignore` contains `public/media`.
- E2E (default build, flag off): no video UI on home, nav or footer; `/tutorial` shows the note.
- E2E with the flag on (a dedicated build or a test-only toggle): at 390x844 portrait, clicking the home card requests `promo-*-9x16.mp4`; at 1280x900, `promo-*-16x9.mp4`; no media request happens before the click; a chapter click seeks.
- Visual QA screenshots at 390 and 1280 px in en, es and de.
- After deploy: real playback checked on desktop and a phone (portrait promo, subtitles on).
